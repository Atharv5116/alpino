Alpinos Print Sans (AlpinosPrintSans-Regular.ttf, AlpinosPrintSans-Bold.ttf)

Subsets of Liberation Sans 2.1.5 (metric-compatible with Arial): Latin, Latin-1, Latin
Extended-A, general punctuation, arrows and a few symbols; kerning and layout tables
removed. Renamed because the SIL Open Font License reserves the font name "Liberation" for
unmodified copies. Licensed under the SIL Open Font License 1.1 -- see LICENSE-OFL.txt.

Embedded in the Purchase module print formats by alpinos.purchase.print_fonts so the
browser Print and the downloaded PDF (wkhtmltopdf) lay text out with the same font.
