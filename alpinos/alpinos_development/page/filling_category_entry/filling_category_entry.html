Filling Process Category
The category is the master trigger for filling. A machine carries one, an SKU lists the ones it may run on, and production compares the two before a line is assigned.
Machines In This Category
Set on the machine, not here: one machine belongs to one category, so the machine screen is where it is chosen.
Items Allowed On This Category
Set on the item, under Filling. An SKU may list several categories, so the list lives on the item rather than here.
